## 📌 Projetos em Destaque

### 🔹 Sistema de Chamados — Help Desk

Simulação de um sistema de suporte técnico para abertura e gerenciamento de chamados, com foco na organização das solicitações e no atendimento aos usuários.

**Tecnologias:** JavaScript e Node.js.

### 🔹 Diagnóstico e Recuperação de Perfil de Usuário no Windows

Estudo de caso prático baseado na investigação de uma falha no carregamento do perfil de usuário do Windows.

O projeto documenta a identificação de perfis temporários, a verificação do perfil ativo, a execução do comando `sfc /scannow` e a validação do funcionamento do sistema após a recuperação.

**Ferramentas:** Windows e Prompt de Comando.

**Aprendizados:** diagnóstico de problemas, integridade de arquivos do sistema, investigação técnica e validação de resultados.
